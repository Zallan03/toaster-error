An entry for the [make.fun bounty "The Funniest Toaster Error Message"](https://make.fun/bounty/u-eager-stork-81-9647-the-funniest-toaster-error-436406cd) — one line, at most 120 characters: the error message a kitchen toaster shows its owner when something goes wrong.

## The entry

> ERROR: Complaint filed. It will be toasted in 6-8 weeks.

The toaster as a tired civil servant: the owner's complaint has been filed through the proper channels — and, like everything else this appliance handles, it will be toasted in 6-8 weeks.

## How it works

`main.ts` writes the single line to `/output/entry.txt` (no trailing newline). Run it with Node 22 or later:

```sh
node main.ts
```
